## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executor tools bundled together with a universal loader called xcutorsLoader, designed for Windows desktop users.

### Which executors are included in the pack?

The pack includes Volt, Synapse Z, Potassium, Wave, and the universal xcutorsLoader that lets you switch between them from a single interface.

### Is XCutors free to use?

Yes. The xcutorsLoader and all included executor packages are available for free download from this repository's Releases page.

### What are the system requirements?

You need Windows 10 or Windows 11 (64-bit), at least 4 GB of RAM, and .NET Framework 4.8 or later installed.

### Why does my anticomponent flag the files?

Script executors inject code into running processes, which heuristic anticomponent engines commonly flag as suspicious. You can safely add the XCutors folder to your exclusion list.

### How do I update to the latest version?

Visit the Releases page on this repository, download the newest ZIP, and extract it over your existing installation. Your saved scripts and settings will be preserved.

### Can I load my own custom Lua scripts?

Absolutely. Use the 'Open Script' button or drag-and-drop any .lua file into the executor window. You can also paste scripts directly into the editor pane.

### Where can I get help or report bugs?

Open an issue on this GitHub repository or join the community Discord server linked in the repository sidebar. Please include your OS version and executor name when reporting.

### Does XCutors support script hubs or pre-built script libraries?

Yes. xcutorsLoader includes a built-in script hub with categorized community scripts that you can browse and execute with a single click.

### Is there a portable version that requires no installation?

Yes. The release ZIP is fully portable — simply extract it to any folder or USB drive and run xcutorsLoader.exe directly. No installer or registry entries are needed.
